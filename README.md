# Campus Life Super App 2025/2026

## Description
The Campus life app is a web-based application designed to help students explore events, clubs, and announcements on campus all within a single place. It provides an interactive and responsive interface for discovering events, joining clubs, and staying connected to activities all around campus.

---

## Technologies Used
- **HTML** – Semantic structure and accessible markup
- **CSS** – Custom styles for cards, navigation, and layout
- **Bootstrap** – Responsive, grid system, and components
- **JavaScript** –driven functionality, dynamic content handling
-GitHub** – Version control and project deployment
- **Pages** – Hosting and deployment of live site
